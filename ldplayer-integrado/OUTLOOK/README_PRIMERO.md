# Gestoría Díaz Outlook V29 — Lector de código IMSS

1. Cierra todas las versiones anteriores de OUTLOOK. No modifiques IMSS V22.
2. Abre Gestoria_Diaz_OUTLOOK_V29_CODIGO_IMSS.pyw.
3. Ejecuta INSTALAR.bat desde %%LOCALAPPDATA%%\GestoriaDiaz\AplicacionesV29\Outlook si aún faltan dependencias.
4. IMSS V22 y Outlook V29 deben correr en la MISMA computadora y sesión de Windows.
5. Inicia un trámite autorizado y revisa en Outlook estado CODIGO_DISPONIBLE.
6. Después IMSS V22 debe mostrar CODIGO_ENVIADO_AL_CELULAR al recibirlo.

Los archivos y credenciales locales del usuario NO se incluyen dentro de este instalador.
No ejecutes al mismo tiempo V27/V28/V29: comparten el puerto 8797.
