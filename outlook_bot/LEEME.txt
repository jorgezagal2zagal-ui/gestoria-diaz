GESTORIA DIAZ - OUTLOOK CON OMISION Y NAVEGADOR ALTERNATIVO

1. Extrae TODO el ZIP en una carpeta.
2. Instala Python 3.10 o superior y navegadores compatibles.
3. Ejecuta INICIAR.bat. Necesita Internet para instalar Selenium y el
   controlador oficial del navegador la primera vez.
4. Importa tus cuentas (correo:contrasena) y pulsa INICIAR.

Usa hasta DOS navegadores instalados por cuenta. Prioridad: Chrome, Edge,
Firefox. Ejemplos: Chrome+Edge o Chrome+Firefox. Si solo tienes uno, solo
puede hacer ese intento. Cada intento abre una sesion privada nueva.
Si no puede usar contrasena, queda en una pantalla desconocida o vence la
espera, cierra ese intento y prueba el otro navegador. Si ambos fallan,
marca Omitido y pasa al siguiente correo de la lista.
Cada pantalla tiene espera limitada; cada intento dispone de hasta150segundos
ademas del arranque/instalacion del controlador. No sortea CAPTCHA ni
verificaciones de Microsoft. Puedes completarlas manualmente durante la espera.

OMITIR CORREO / SIGUIENTE: interrumpe la cuenta actual y avanza.
DETENER: detiene la cola y cierra el navegador de este intento.
Cuando abre Outlook correctamente, mantiene la bandeja abierta para que la uses.
No lee ni envia mensajes. Para avanzar pulsa OMITIR CORREO / SIGUIENTE.
Deten la cola para importar o quitar cuentas. INICIAR recorre la lista desde
el principio. La columna Estado muestra esta sesion; el registro conserva
los resultados aunque cierres el panel.

Las contrasenas quedan en memoria. No se escriben contrasenas en archivos ni en
mensajes de error. La tabla oculta contrasenas salvo que marques Mostrar.

Validacion: pruebas simuladas de recuperacion y prueba real de la interfaz Tk.
No se han probado cuentas reales de Microsoft ni navegadores Windows aqui.

PANTALLAS RECUPERABLES
- Too Many Requests: recarga inmediatamente una vez la misma pagina.
  Si el limite persiste, detiene la cola para intentar mas tarde; no cambia
  de cuenta o navegador para seguir haciendo solicitudes.
- A quick note about your Microsoft account: pulsa OK en el aviso oficial
  de privacynotice.account.microsoft.com y continua hacia Outlook.
- Password sign-in isn't available: cierra el intento, abre el navegador
  alternativo e intenta de nuevo. Si tambien falla, omite el correo.
- Almost there / Just one more step to verify it's you: omite directamente
  esa cuenta y pasa a la siguiente. No pide el codigo ni prueba otro navegador
  para esa cuenta. En la tabla aparece Omitido: verificacion adicional.

REGISTRO DE RESULTADOS
VER REGISTRO muestra la fecha, el correo, el resultado y el motivo.
Entró a la bandeja: Outlook llego a abrir la bandeja de esa cuenta.
No logró entrar: fallo el acceso o pidio verificacion adicional.
Omitido: lo saltaste manualmente antes de entrar.
Interrumpido: detuviste el intento o Microsoft limito las solicitudes.
Las cuentas que no se intentaron no se marcan como fallidas.
Se anade una fila por intento de cuenta, sin borrar los resultados anteriores.
Un acceso exitoso se guarda antes de esperar a que pases al siguiente correo.
Actualizar recarga la lista; Exportar CSV permite guardar una copia para Excel.

En Windows se guarda automaticamente en:
%LOCALAPPDATA%\GestoriaDiazOutlook\registro_correos.csv
El registro solo contiene correo, fecha, resultado y motivo; nunca contrasenas.
